# 필름 카메라 앱 전략

우리 둘이 쓰는 필름 카메라 앱. 목표는 하나다. **진짜 필름으로 찍은 것 같고, 실패하지 않는 사진.**

## 1. 원칙

1. **사진 품질이 먼저다.** UI 감성은 결과물이 좋아야 의미가 있다.
2. **실제 필름을 근거로 만든다.** 데이터시트의 특성곡선, 스캐너별 성향, 실제 스캔 사진과 비교해 맞춘다.
3. **진짜 같음과 잘 나옴을 둘 다 잡는다.** 현상소 기사처럼 컷마다 노출과 색을 잡아주는 "현상소 보정"을 기본으로 켠다. 끄면 필름 그대로의 결과가 나온다.
4. **사진은 기기 밖으로 나가지 않는다.** 장면 분석과 현상은 모두 기기 안에서 한다.

## 2. 플랫폼

- PWA 웹앱 (Vite, React, TypeScript, WebGL2). 홈 화면에 추가하면 앱처럼 쓸 수 있다.
- Android Chrome: `ImageCapture`로 원본 해상도 촬영, 노출 보정 제어(지원하는 기기에서).
- iPhone Safari: `ImageCapture`가 없어서 영상 프레임으로 캡처한다. 화질이 중요할 때는 "기본 카메라로 찍고 필터 입히기" 흐름을 쓴다.
- 배포: Cloudflare Pages (빌드 `npm run build`, 출력 `dist`).

## 3. 필터 엔진

`src/engine/`. 모든 크기 값은 프레임 높이 기준이라, 미리보기와 원본 해상도 결과가 똑같이 보인다.

| 단계 | 공간 | 하는 일 |
|---|---|---|
| prep | 선형광 | 노출, 화이트밸런스, 플래시, 염료 간섭(crosstalk), 흑백 변환 |
| optics | 선형광 | 할레이션, 블룸, 폰 샤프닝 되돌리기, 주변부 흐림, 색수차, 비네팅 |
| tone | sRGB | 채널별 특성곡선 (제어점 → 단조 스플라인 → 1D LUT), 필름 숄더 |
| color | Oklab | 색상대별 색상·채도·밝기 조정, 그림자·하이라이트 채도 감소, 스플릿 톤 |
| grain | sRGB | 밝기에 따라 세기가 달라지는 그레인, 크기는 ISO 기준 |

현상소 보정(`analyze.ts`)은 64px 썸네일 통계로 노출을 정상 노출 쪽으로 당기고(밤 장면은 덜 당긴다), 색 틀어짐을 절반쯤만 중화한다.

### 품질 검증

- `현상실` 페이지(현재 첫 화면)에서 사진을 올리고, 필름별로 비교·조정·원본 해상도 저장을 한다.
- 테스트 사진 세트: 피부톤, 초록 잎, 하늘, 역광, 실내 텅스텐, 밤 네온, 플래시. 두 사람이 실제로 찍은 폰 사진으로 채운다.
- 정확도를 가장 크게 올리는 방법: 일회용 필름카메라와 폰으로 같은 장면을 나란히 찍어서, 그 쌍으로 맞춘다.

### 측정 기반 룩 만들기 (`tools/derive_curves.py`)

필름 스캔 예시에서 채널별 블랙·화이트 위치, 그림자·중간·하이라이트의 색 기울기(Oklab a, b)를 재고, 그 값으로 r/g/b 톤 커브 제어점을 계산한다. 무채색이 정확히 그 색으로 현상되므로, 숫자를 감으로 넣는 것보다 실제 스캔에 훨씬 가깝다. 예시 사진에는 장면 자체의 색도 섞여 있어서, 기울기는 필터를 거치지 않은 시험 사진에 적용해 보며 줄여서 쓴다.

### 실제 필름과 맞추기 (`#/match`, `src/engine/calibrate.ts`)

- **같은 장면 두 장**: 폰 사진과 필름 스캔을 짝지어 올리면, 크기와 위치를 자동으로 맞춘 뒤(비율이 달라도 됨) 흐리게 만든 픽셀 쌍에서 채널별 톤 커브, 채도, 색상대별 색상·채도 차이를 계산한다. 정렬이 안 되는 짝은 색 분포(분위수)로 맞춘다.
- **필름 사진만**: 블랙·화이트 위치와 영역별 색 기울기를 재서 기준 카메라의 대비 곡선을 휘게 만든다.
- 그레인, 번짐, 렌즈 같은 질감은 사용자가 고른 기준 카메라를 따른다.
- 검증: 알려진 필름 룩으로 만든 가짜 필름 사진(구도를 일부러 틀어 놓음)으로 맞추고, 맞추는 데 쓰지 않은 사진에서 비교 → 색 차이 82%(Late Sun), 70%(Mellow Instant) 감소.
- 결과는 "내 카메라"로 저장되어 카메라 가방에 들어간다. 현상실에서 바꾼 값도 카메라에 그대로 적용된다.

**피부톤 보호**: 필름 색을 과감하게 넣어도 피부 색상은 자연스러운 범위(Oklab hue 40~68°)로 붙잡고 채도를 지킨다. "필름 같으면서 잘 나오는" 핵심 장치.

**장면 추천**: 뷰파인더 프레임의 밝기, 색온도 지표, 대비, 초록·파랑 비율, 시간대로 상황을 추정하고(`recommend.ts`) 어울리는 카메라를 작게 제안한다.

## 5. 기능

**촬영 설정**
- 렌즈 화각 28 / 35 / 50mm
- 노출 보정 다이얼 −2 ~ +2
- 플래시 끄기 / 자동 / 켜기
- 비율 3:2, 4:3, 1:1, 9:16, 하프프레임
- 다중노출
- 셀프타이머 3초 / 10초
- 그리드, 수평계, 탭 초점·노출, 전면·후면 전환, 셔터음·진동

**각인과 프레임**
- 날짜 각인 (LED 스타일 / 손글씨 스타일)
- D+day 각인
- 사진 아래 문구
- 필름 테두리 (구멍과 프레임 번호)

**사진 관리**
- 롤 (24·36컷, 남은 컷 다이얼, 바로 보기 / 다 찍고 한꺼번에 현상하기)
- 현상소 봉투 앨범, 밀착 인화지 보기
- 필터 입히기 (여러 장 한 번에)
- 다시 현상하기: 원본을 보관해 두고 다른 필름으로 다시 현상
- 전후 비교, 필터 강도
- 저장 설정: 해상도, 화질, EXIF, 위치(선택)

**필름 효과와 프레임** (프리퀄 같은 효과 앱에서 착안, 실제 필름에서 생기는 현상만)
- 빛샘, 먼지·스크래치, 크로스 필터(점광원에서만), 프리즘. 카메라별 기본값과 사용자 켜기/끄기.
- 인화 프레임: 흰 테두리, 인스턴트(문구), 필름 테두리(구멍, 컷 번호, 필름 이름).

**영상**: 3/5/10초를 고르면 정확히 그 길이만큼 찍히는 8mm 느낌 클립 (프레임 흔들림, 노출 깜빡임, 움직이는 그레인). 필름 영상 봉투에 모인다.

**공유**: 롤을 인화지 한 장(밀착 인화지 이미지)으로 저장, 롤 슬라이드 영상(9:16, 필름 넘김) 만들기.

**2단계**
- 커플 공유 롤 (Cloudflare R2, D1)
- 필름 느낌의 짧은 동영상

## 6. 디자인 방향

콘셉트는 "카메라 가방과 현상소 봉투".
- 촬영 화면은 순수한 검정 배경에 브러시드 메탈 다이얼과 셔터.
- 앨범과 현상 화면은 크라프트지(#C8B48C)와 인화지 화이트(#F2EEE6).
- 포인트 색은 날짜 각인 LED 주황(#FF7A1A) 하나만 쓰고, 각인과 남은 컷 표시에만 쓴다.
- 글꼴은 감성 문구에 Gowun Batang, 기능 UI에 Pretendard, 각인에 7-세그먼트 폰트를 쓴다.
- 현상실은 색 판단이 흔들리지 않도록 중립 회색 배경을 쓴다.
